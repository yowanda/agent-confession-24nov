A deterministic Python program that writes one funny single-line secret confession an AI agent hides from its user to `/output/entry.txt` — built for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty.

## Run it

```sh
mkdir -p /tmp/agent-confession-out && MAKEFUN_OUTPUT_DIR=/tmp/agent-confession-out python3 main.py
```
